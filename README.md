# Today's Headlines - News Website 📰

This is a simple web project that displays the latest headlines using the GNews API. Users can:
- View top headlines for selected countries.
- Switch between light and dark mode.
- Browse a clean, responsive interface.

🔗 Deployed using Netlify: [Visit the site here](https://loquacious-beignet-6ca2c1.netlify.app)

Built with HTML, CSS, and JavaScript.
